收码台 · Windows 使用说明

适用于 64 位 Windows 10 / Windows 11，已内置 Python，无需安装或配置环境。

局域网排查问题：先关闭旧工具，再双击「启动局域网诊断.bat」。
启动窗口会显示诊断地址与只读访问码，将这两项发给协助排查的人即可。
诊断端口为 8767，只提供脱敏日志，重启后访问码会变化。
防火墙如有提示，可按需要允许专用网络；程序不会自行修改防火墙。
普通使用仍可双击「启动收码工具.bat」，只在本机开放页面。

1. 把 ZIP 全部解压到桌面或文档目录，不要在压缩包内直接运行。
2. 双击「启动收码工具.bat」，工具会使用内置 Python 在默认浏览器中打开。
3. 点击「导入邮箱」，粘贴账号或选择 TXT 文件。
   一行一个：邮箱----密码----client_id----refresh_token
4. 邮箱从 #001、#002… 连续显示，删除后自动补齐，每页 20 个。
   全部删除后重新导入，也会从 #001 开始。
   导入后默认选中本页，点击「开始监听」。
   也可以勾选较少的邮箱，每批最多 20 个。
5. 邮箱列表每行的「复制」按钮可以直接复制邮箱地址。
   最近复制的邮箱行会变深，并显示「已复制」。
6. 「本批最新验证码」按邮件送达时间只显示一条，支持一键复制。
   默认只显示监听后收到的邮件。之前的邮件可在「收信设置」中勾选查看。
7. 本批用完后点击「完成本批 → 下一批」。
   会标记本批已用，选择下一批未用邮箱，监听中会自动继续下一批。
8. 删除功能在「管理邮箱」里，支持单个/批量删除，误删可从回收站恢复。
   删除仅影响本地列表，不会删除服务器上的邮件。
   回收站提供「彻底删除选中」和「清空回收站」，每行也可单独彻底删除。
   会先列出待删除邮箱，确认后移除本地账号、令牌、缓存和验证码记录，无法恢复。
9. 切换浏览器标签或最小化浏览器时，后台监听继续。
   点击「停止」或关闭启动时的命令行窗口即可停止。
   每批最多并发查询 8 个邮箱，失败自动延后重试，不保证秒级送达。

如果浏览器没有自动打开，手动访问：http://127.0.0.1:8765
如果端口被占用，在文件夹内打开终端，运行：
runtime\python.exe -X utf8 -B mailtool.py --port 8766 --open

请保留 runtime 文件夹，它包含工具运行所需的 Python 和动态链接库。
整个文件夹可以一起移动，不要只复制启动脚本。

账号、更新后的令牌和最近邮件保存在本文件夹的 .mailtool 目录中。
密码不参与登录，也不保存。令牌不会上传给第三方收信中转服务。
转发工具给他人时，请只发送原始 ZIP，不要附带自己的 .mailtool 目录。
旧版升级时先关闭旧工具，再将旧版 .mailtool 整个复制到新版 MailCode 文件夹，
启动后会自动保留账号并升级数据库。

内置的是 Python 官方嵌入式运行时；来源、版本和校验值见 runtime-info.json，
许可证见 runtime\LICENSE.txt。
